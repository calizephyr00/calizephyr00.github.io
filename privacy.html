Privacy policy

Effective November 19, 2026

Home Control is a personal Mac app used by one household. It has no servers, no accounts and no other users. This page explains what it does with Google user data.

Data it accesses

With the owner's permission, granted on Google's Nest consent screen, Home Control reads and changes the Nest thermostat the owner selects there, through Google's Smart Device Management API. That covers the thermostat's mode, target temperatures, indoor temperature and humidity, heating or cooling status, eco setting, connection status and room name.

How it uses that data

Only to show the thermostat in the app's menu bar panel and to carry out changes the owner makes there. Nothing else.

Where it is stored

On the owner's own Mac only. The app keeps the Google sign-in token it needs to stay connected in a local settings file. Thermostat readings are held in memory while the app runs and are not saved.

Sharing

Home Control does not send Google user data to any server other than Google's own APIs. It does not share, sell or transfer the data to anyone, does not use it for advertising, and contains no analytics or tracking.

Google API Services User Data Policy

Home Control's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be withdrawn at any time from the Google account's third-party connections, or from the Nest app's Works with Google / partner connections settings. Quitting and deleting the app removes the locally stored token.

Contact

Questions about this policy can be raised by opening an issue on this site's GitHub repository.
